Đặt một font `.ttf` / `.otf` **có đủ dấu tiếng Việt** vào thư mục này. Nếu có nhiều file,
font đầu tiên theo thứ tự tên file sẽ được dùng. Muốn chỉ định font khác: `--font path/to/font.ttf`.

Font miễn phí trên Google Fonts có bộ ký tự tiếng Việt, hợp với truyện tranh:
**Patrick Hand**, **Itim**, **Sriracha**. (Comic Neue *không* có dấu tiếng Việt.)

Không có font nào ở đây thì dùng font hệ thống: Arial trên Windows/macOS, DejaVu Sans trên Linux
(đều có dấu tiếng Việt).
